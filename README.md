# justbob
heyo! this is just bob, a little buddy that grows with how long you have stayed in the tab. there are many upgrades you can give bob, and for every minute you stay with bob, he grows. with images to simulate every age. bob lives as long as you live. enjoy!

--

## installation guide :)

make sure you also have node.js before starting!!

### 1 Clone the repository.
Type in this command: `git clone https://github.com/gabe1031bit-school/justbob` into your OS's native terminal.

### 2 Navigate to the folder to where it cloned into.
Type in this command: `cd justbob` for any operating system.

### 3 Install Firebase CLI.
_But first..._ make sure you have a Firebase/Google account. To check, try to login to firebase. Follow all the steps they give you.

To install the Firebase CLI, type in this command `npm install -g firebase-tools` into your OS's native terminal.

### 4 Login into Firebase!

To login, use this command, `firebase login`.

### 5 Initialize the folder for Firebase.

To initialize the folder for Firebase, use this command `firebase init`.

Make sure to choose `Hosting`, then `Create A New Project` (_name it justbob-gvhc-[whatever you want after this]_), then `.`, then `n` to the rest of the questions.

### 6 Deploy!

To deploy, just use the command `firebase deploy`. That's it. Enjoy **Just Bob**!
